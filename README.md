## Реализованный функционал
1. Реализован класс HeadHunterAPI, наследуется от абстрактного класса AbstractHHApi.
   Класс для взаимодейтсвия с API HeadHunter.
   В классе определены следующие методы:
- метод (приватный, вызывается только внутри класса) ***__connection_setup*** отправляет тестовый запрос к базовому URL API для проверки доступности сервиса и корректности настроек. Выводит статус код ответа в консоль, а также причину ошибки при неудачном запросе.
- метод ***public_connection_setup*** предоставляет публичный интерфейс для вызова приватного метода ***__connection_setup*** проверки соединения. Используется для тестирования подключения перед выполнением основных запросов.
- метод ***get_vacancies*** выполняет поиск вакансий на HeadHunter по заданному ключевому слову. По умолчанию ищет в Нижнем Новгороде (area=66) и возвращает только вакансии с указанной зарплатой.

2. Реализован класс Vacancy. 
   Класс для представления и работы с вакансиями. Обеспечивает хранение информации о вакансиях, валидацию данных, сравнение вакансий по зарплате и преобразование в удобный формат.
- метод (приватный, используется только внутри класса) ***__validate_salary*** валидирует значение зарплаты. 
- метод ***__lt__*** сравнения вакансий по нижней границе зарплаты (меньше). Принимает для сравнения другую вакансию и возвращает True, если текущая вакансия имеет меньшую зарплату.
- метод ***__le__*** сравнения вакансий по нижней границе зарплаты (меньше или равно). Принимает для сравнения другую вакансию и возвращает True, если текущая вакансия имеет меньшую или равную зарплату.
- метод ***__eq__*** сравнения вакансий на равенство по нижней границе зарплаты. Принимает для сравнения другую вакансию и возвращает True, если зарплаты равны.
- метод ***__str__*** возвращает строковое представление вакансии.
    
3. Реализован класс JSONSaver, наследуется от абстрактного класса AbstractJSONSaver.
   Класс для работы с JSON-файлом вакансий.Реализует операции сохранения, загрузки, поиска и удаления вакансий в формате JSON, предотвращает дублирование.
- метод (приватный, используется только внутри класса) ***__load(self)*** загружает данные из JSON-файла. Возвращает список словарей с данными вакансий. Если файл не существует, возвращает пустой список.
- метод (приватный, используется только внутри класса) ***__save*** сохраняет данные в JSON-файл.
- метод ***add_vacancy*** добавляет вакансию в файл.
- метод ***get_vacancies*** возвращает вакансии, соответствующие критериям поиска.
- метод ***delete_vacancy*** удаляет вакансию из файла.

4. В модуле ***utils*** реализованы следующие вспомогательные функции:
- функция ***filter_vacancies*** фильтрует вакансии по ключевым словам в описании.
- функция ***get_by_salary*** фильтрует вакансии по диапазону зарплаты.
- функция ***sort_vacancies*** сортирует вакансии по убыванию зарплаты.
- функция ***get_top(vacancies*** возвращает топ N вакансий из списка.
- функция ***print_vacancies*** выводит вакансии в читаемом формате. Использует строковое представление вакансий (метод __str__ класса Vacancy), разделяет вакансии горизонтальной линией для лучшей читаемости.

5. В модуле ***main.py*** реализвана функция ***user_interaction*** для проверки работы модулей ***hh_api.py***, ***vacancy.py***, ***json_saver.py***, ***utils.py***.
Запустите код в модуле ***main.py***
Следуйте инструкциям в консоли.
- введите поисковый запрос, например: "Python".
- введите количество вакансий для вывода (топ N вакансий).
- введите ключевые слова для фильтрации (через пробел).
- введите диапазон зарплат (формат: min-max).

Программа сохраняет вакансии в файл data/vacancies.json
